# 10 · 交付位置、补缺与打包验收

2026-11-26，在本地 FastAPI、SQLite 测试库和 MySQL 8.4 隔离库验证。MinIO 使用私有桶。使用合成鞋服 SKU，迁移从空库执行至 `0015_batch_lists`，随后升级至 `0016_discard_batch_item`。

| 场景 | 实测 |
| --- | --- |
| AC-09、AC-38 位置配置 | 双 SKU 各 2 主图、3 详情、1 视频，共 12 个不同位置。单 SKU 5 个位置用例记录了独立鞋面、鞋底模块及视频缺口。 |
| AC-17 规格、模块和预留 | 鞋面批准图只匹配鞋面位置，手工采用到鞋底返回 `409`。MySQL 中两个请求同时补做同一位置，返回 `202` 和 `409`。取消未发出的任务后位置恢复可补。 |
| AC-18 清单调整和导出 | 5 位置部分包的清单列全缺口，唯一采用文件字节一致。调整为仅含已采用位置后可生成完整包，ZIP 完整性检查通过。改变比例和分辨率只移除失配采用，旧下载返回 `409`，原资产仍保留。 |

复验入口为 `apps/server/tests/module06/test_m2_delivery.py` 和 `test_m2_mysql.py`。后一项需要 `STUDIO_M2_MYSQL` 及 MinIO 连接配置，支持模拟方舟或受控使用真实方舟。ZIP 用例使用固定归档样本。真实成片的确认、采用与包内视频由 M3-14 验收。
