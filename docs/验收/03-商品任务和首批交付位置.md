# 模块 03｜商品、任务和首批交付位置

验收日期为 2026-11-22。分支为 `develop`。覆盖 AC-01、AC-33、AC-34 在 M1-03 中的场景。

商品资料使用按品类定义的字段，记录已确认值和依据。更新资料产生新的事实版本，旧版本保留原字段及实拍文件版本。同一实拍文件只能绑定一个 SKU。商品卡片及任务页读取受会话保护的缩略图，读取原件仍按单独权限授权。

新建制作先选商品，再选主图、详情素材或带货视频，并支持修改自动命名。商品、内容与首批位置一起保存。初始范围按「SKU × 选定用途」各建一个待补齐位置。交付位置和生成预留是独立对象，预留仍按相应后续模块的时点建立。

| 验收场景 | 实测结果 |
| --- | --- |
| AC-01 商品事实与实拍 | 白色和红色低帮鞋分别上传实拍到 MinIO，读回不同实拍版本。错绑返回 `409`，跨公司读取返回 `404`。鞋服与美妆表单显示各自字段。缺标签、容量及包装事实的面霜可加入草稿，界面列出缺项。后端生成前置校验单测覆盖缺资料及实拍失效。 |
| AC-33 新建制作 | Playwright 验证自动命名、修改名称、关闭或按 Escape 返回、保留商品和范围，以及上传实拍后保存并选中。只选主图的两个商品生成两个待补齐位置。创建路径只执行数据库写入与读取。 |
| AC-34 显式添加 | 商品卡片开启独立新建流程。取消后已有任务仍有原来的两个位置。通过「添加商品到本次制作」加红色 SKU 后共有三个主图位置。旧位置 ID 保留，刷新后可从全部任务继续。 |
| 权限与原子写入 | 两租户及只读角色通过真实 API 或自动回归验证拒绝未授权写入。SQLite 模拟位置写入失败，确认任务、成员与位置均未留下。MySQL 8.4 实际迁移到 `0003_products_tasks`，`alembic check` 无差异。 |
| 浏览器与构建 | 使用真实 MySQL、Redis、MinIO 以及仓库的异色和美妆样本图片。390×844 视口无横向溢出，三个 SKU 的缩略图正常加载。前端 lint、类型、测试、生产构建和源码行数检查通过。后端 34 项测试、Ruff 和严格 mypy 通过。 |

生成入口接入时须调用服务端 `require_generation_inputs`，并结合模板、品牌规则和执行快照复验属于对应 SKU 的事实与实拍。提示词编辑器在 M1-04 接入，真实生成与模板冲突在 M1-06 联验。多模块或多张数清单，以及既有采用的保留和历史导入，分别在后续交付与迁移任务验收。
