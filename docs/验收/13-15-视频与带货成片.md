## Studio 功能回归

- 单条视频片段可直接排队。带货成片按 SKU 确认分镜，确认绑定草稿、事实和交付规格，提交后冻结提示词、参考及分镜。批量提交受理多个独立候选并验证幂等。
- 12 坑位用例覆盖两 SKU、10 张图先受理、2 条视频分别待确认。5 坑位用例覆盖三入口从成片确认到归档、区间播放、驳回时段标注、整条返工、批准采用和 ZIP 下载。应用集成测试使用可完整解码的本地 MP4，核对交付包字节和冻结分镜。
- 浏览器覆盖快捷、画布和批量分镜，检查空画面及错误时长拦截，并确认 390×844 手机视口批量提交返回 HTTP 202。截图在 `output/playwright/module-m3/`。
- 三入口提示词建议测试覆盖应用、撤销和草稿版本约束。测试使用模拟文本响应，应用建议时没有新建视频执行或确认分镜。
- Alembic 在独立 SQLite 库迁移至 `0017_video_storyboard`。前端生产构建、Vitest、ESLint 和后端 Ruff 通过。
