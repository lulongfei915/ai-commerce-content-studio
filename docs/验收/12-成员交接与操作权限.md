# 12 · 成员管理、交接与动作权限验收

2026-11-26，使用 SQLite 双租户 API 测试及 MySQL 隔离租户的 390×600 Chrome 验收。API 样本包含管理员、设计师、审核员、只读成员及关闭下载授权的设计师。

| 场景 | 实测 |
| --- | --- |
| AC-16、AC-40 业务权限 | 逐一直接请求成员管理、生成、终审、采用和交付包下载。未授权动作返回 `403`。允许的角色进入业务校验。关闭下载授权后仍可生成和采用，下载受限。 |
| AC-41 停用交接 | 自停用、最后管理员降级、跨租户接手人均被拒绝。停用后原会话读取及终审返回 `401`。任务和商品负责人变更，创建者、资产版本及原审核人保持。 |
| AC-42 移动端 | 在手机尺寸打开停用交接、核对确认按钮可见、按 Escape 返回触发按钮。选择有效接手人，提交后刷新，成员保持停用。 |
| 审计 | 生成提交、恢复、核实、取消、终审和采用记录操作者。授权下载受理、交付包导出及成员交接写入公司操作记录。 |

复验入口为 `apps/server/tests/module02/test_team.py`、`test_m2_permissions.py` 和 `node apps/web/scripts/verify-m2.mjs`。验收截图位于 `output/playwright/module-m2/team-handover-390x600.png`。
