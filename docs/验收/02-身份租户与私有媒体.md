# 模块 02｜身份、租户与私有媒体

- 验收日期：2026-11-22
- 分支：`develop`
- 范围：AC-16、AC-40 的会话、租户、角色和文件访问子场景

登录创建有时限的服务端会话，浏览器通过 HttpOnly Cookie 恢复登录。当前公司、成员状态、角色及下载开关由服务端查询。管理员可设置动态验证码。Redis 限制重复登录尝试。其他业务模块可直接复用此权限检查。

上传依次申请文件 ID、传输文件并确认完成。服务端核对大小、真实类型、解码和规格，再保存到私有存储。同公司的有效成员可查看文件规格。原件读取和每次 Range 请求都检查单独下载授权。跨公司查找返回 `404`，同公司有查看权但无下载权时返回 `403`。

| 验证 | 实测结果 |
| --- | --- |
| 自动回归 | 后端 29 项测试通过，覆盖会话有效期、退出撤销、两租户四角色、CSRF、配置动态验证码后的登录与重放拒绝、错误媒体、文件超限以及续传鉴权。前端登录及退出测试通过。Ruff、严格 mypy、前端类型检查与生产构建通过。 |
| MySQL 和 Redis | 独立 MySQL 8.4 库完成 `0001` 到 `0002_identity_media` 的迁移。真实 API 使用持久会话与 Redis 登录限流。 |
| MinIO | 使用真实 JPEG 和 1280×720 MP4 完成传输、确认和读回，视频识别时长为 5.04 秒。对象存储匿名读取返回 `403`。API 读取返回 `200`，Range 读取返回 `206` 且字节匹配。撤销下载授权后，原会话的下一次 Range 返回 `403`。 |
| 浏览器 | Playwright 连接真实服务验证登录、刷新恢复当前公司、显示角色和下载授权、390×844 下退出并返回登录页。 |

本轮采用 8 小时会话和 1 小时上传有效期。默认图片上限 20 MiB，视频上限 100 MiB。媒体存储与真实授权校验已验证。依赖批准、来源和采用版本的交付校验随交付模块接入，成员管理及交接由模块 12 实现。
