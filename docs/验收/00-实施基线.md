## 图片 API 适配器补充

- 已新增 `apps/server/app/adapters/ark_image.py`，按图片生成 API 的 `POST /images/generations` 契约构造 Seedream 5.5 请求。
- 支持文生图、单图/多参考图、URL 或 Base64 输入、透明背景、PNG/JPEG、URL/Base64 响应和图层拆分参数校验。
- `ARK_API_KEY` 使用 `SecretStr` 读取，不写入日志、响应或异常正文。`ARK_IMAGE_MODEL` 可填写模型 ID，也可在模型开通后替换为 Endpoint ID。
- 供应商 429 不自动重试，适配器只返回脱敏分类、HTTP 状态、供应商错误码、请求 ID 和 `Retry-After`。这是为避免超时或限流时重复产生付费调用。
- 可重复执行的本地烟测命令为 `PYTHONPATH=apps/server uv run --project apps/server python -m app.entrypoints.smoke_image`。成功时会下载结果到被 Git 忽略的 `.artifacts/ark-image-smoke/`。
