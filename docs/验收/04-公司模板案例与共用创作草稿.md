# 模块 04｜公司模板、案例和共用创作编辑器

验收日期为 2026-11-22，交付分支为 `develop`。本次验收覆盖 AC-06～08、AC-35、AC-36 的图片快捷创作场景。Playwright 使用真实 MySQL 8.4、Redis、MinIO 和项目的鞋服测试图片。

管理员可在公司模板中保存草稿、发布和查看历史版本，在案例库维护来源和使用范围。制作人员在当前任务按 SKU 和用途打开草稿。每份草稿保存一份提示词、生成参数、模板版本和具体文件版本。模板附带参考与独立参考分别显示。

| 验收项 | 实测结果 |
| --- | --- |
| AC-06 案例检索与授权 | API 按关键词和媒体类型检索到目标案例。浏览器上传并预览私有案例图片，未确认用途的案例可以浏览，添加按钮禁用。服务端拒绝未授权及用途不符的引用。撤回使用范围后，已保存草稿的前置检查定位到相应引用。 |
| AC-07 模板与独立参考 | 新增案例后张数保持 1。显式应用 V2 后张数更新为模板设定的 2，独立案例和模板附带案例同时存在。上传独立参考图写入具体文件版本，保留正文与张数。补齐商品事实和实拍后，不带额外参考的草稿也通过前置检查。 |
| AC-08 字段校验 | 非法输出张数返回 `422` 并定位到 `parameters.count`，未就绪文件被拒绝。模板停用后，草稿前置检查指向 `template_id`。 |
| AC-35 单一提示词 | 应用模板时选择保留正文，保存并刷新后重新打开同一任务，手写提示词与参考恢复。API 回归覆盖原文前后空白。保存、选择案例、应用模板和检查草稿的浏览器路径没有发起生成。 |
| AC-36 发布与历史 | 创建草稿、发布 V1、修改并发布 V2 后，仍可浏览 V1 原文。空提示词允许保存为草稿，发布时返回字段校验错误。浏览器验证停用确认，API 回归验证重新启用及历史版本保留。 |
| 工程验证 | MySQL 8.4 迁移到 `0004_creative_drafts`，`alembic check` 无差异。Ruff、严格 mypy 和后端 37 项测试通过。前端 lint、类型检查、2 项测试、生产构建和源码行数检查通过。重新生成 OpenAPI 与 TypeScript 类型无差异。 |

本地浏览器证据位于 `.artifacts/module04/`。`m104-mobile.png` 记录 390×844 视口下的草稿、两类参考及停用提示，页面通过无横向溢出检查。
