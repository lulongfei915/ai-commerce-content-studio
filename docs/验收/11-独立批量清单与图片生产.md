| 场景 | 实测 |
| --- | --- |
| AC-04、AC-37 共用作品 | 复用快捷或画布草稿后可独立编辑，引用按目标 SKU 和版本校验。批量批准结果在共用任务作品接口按原版本预览，资产 ID 一致，对应一个匹配候选，画布节点数仍为零。 |

| AC-30、AC-34、AC-36 配置与原子性 | 公共提示词、图片比例与清晰度、数量更新仅影响继承项。已提交输入冻结。复制生成项创建新草稿。换 SKU 清理旧引用。不合格项阻止整批并打开该项编辑。相同请求返回原执行。 |
