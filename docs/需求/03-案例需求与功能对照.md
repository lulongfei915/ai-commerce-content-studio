# CASE-021｜案例需求与功能对照

> 2026-11-18 · 依据：[真实案例](00-真实案例.md)与[当前原型](../../prototype/index.html)。

本文按**原型设计是否覆盖**判断“已有/缺少”。真实模型、公司后台与成本服务待接入，不影响已有设计的判定；接入要求见 [PRD](01-产品需求文档-PRD.md)。

## 1. 案例需求覆盖情况

| 案例需求 | 当前设计 | 已有内容或缺口 | 对应痛点 |
| --- | --- | --- | --- |
| 统一素材生产工作台 | 已有 | 商品、制作、审核、资产与交付在同一流程中衔接 | 员工各用工具，流程靠人串联 |
| 选择商品和场景模板生产 | 已有 | 商品实拍与事实自动带入，提供用途、风格、默认提示词和参数 | 重复写词调参，质量依赖个人经验 |
| 主图、详情素材、带货视频制作 | 已有流程 | 三类用途均可制作审核；按 SKU 配置多个详情模块、数量与规格，视频分镜可编辑并确认 | SKU 多、上新快，素材生产量大 |
| 批量制作与进度管理 | 已有 | 图片/视频清单、公共与单项配置、批量提交、逐输出进度和恢复 | 逐项操作、反复盯生成 |
| 商品与素材关联、复用及追溯 | 已有基本流程 | SKU、用途、版本、输入快照、审核原因关联；可引用同 SKU 已批准素材 | 找图难、重复制作、错用商品和版本 |
| 人工终审与结果回写 | 已有 | 实拍对照、批准/原因驳回、状态记录与指定版本返工 | 素材好看但不符实物，返工意见难追溯 |
| 公司统一维护模板和标准 | 已有 | 模板草稿、默认提示词/参数/初检规则、发布/启停与版本记录；三入口可明确应用 | 标准依赖个人，经验难沉淀 |
| 公司级资产检索与人员交接 | 已有本地流程 | 跨任务按 SKU/品类/场景等查找、查看来源版本、引用批准素材；成员角色限制与停用交接 | 素材散落、难复用，人员变动导致断档 |
| 质量数据积累与持续改进 | 部分覆盖 | 有审核记录；缺质量分析、规则改进和效果评估流程 | 相同质量问题反复发生 |
| AI 一致性初检＋自动拦截 | 已有模拟流程 | 生成保存后先初检，未通过拦截并显示原因，通过后人工终审；异常可重试，真实视觉检查待接入 | 自动初筛减负、阻止问题版本流入终审和交付 |
| 员工无需反复处理水印 | 尚未明确 | 正式服务的输出与必要标识处理方式待确定 | 生成后仍需人工整理输出 |

当前审核流程已补齐案例做法：“生成保存→AI 初检→未通过自动拦截、通过后人工终审→明确采用”。原型初检为预设模拟，真实筛错能力与减负效果待验证。

## 2. 相对案例新增或细化的功能

“新增”指案例正文未明确描述；“细化”指把案例已有方向补成具体操作规则。

| 功能 | 性质 | 当前状态 | 解决的问题 |
| --- | --- | --- | --- |
| 快捷生成、画布、批量制作独立入口 | 新增操作方式 | 共用任务、商品和产出版本，画布显式引用已有作品 | 员工按习惯创作，可直接取用有权限访问的同一作品 |
| 一键优化/撤销、参考图/视频解析 | 新增辅助 | 已有预设建议交互，真实模型待接入 | 不会写词、有参考但描述不清 |
| 多行业商品与品类适配 | 新增范围 | 有鞋服/美妆示例，完整适配待补齐 | 不同品类不能套同一套字段与表达 |
| 新建制作选商品与内容、就地新增商品、任务续作 | 细化制作流程 | 已有 | 补资料绕路、制作范围不清、误改旧任务 |
| 公共配置继承、单项覆盖、唯一提示词 | 细化批量配置 | 已有 | 重复调参、单项差异难处理、多处输入互相覆盖 |
| 逐输出恢复、保存失败只重存 | 细化失败处理 | 已有本地模拟，真实后台待接入 | 一份失败导致整批重做、浪费已完成结果 |
| 分镜确认、指定版本返工 | 细化生产与审核 | 分镜编辑/确认、文字原因和版本返工已有；区域/时间标注待补齐 | 镜头要求不清、返工对象不明确 |
| 批准与采用分开、交付缺口、完整/部分包 | 细化交付 | 已有清单和示例下载 | 生成很多却交不齐、错交版本、手工整理 |
| 成本记录、预算授权、查单与防重 | 新增治理要求 | PRD 已定义，待接入 | 重复付费、重试失控、成本不清 |
| Agent 理解目标、推荐计划与协调执行 | 细化智能体规划 | 第二阶段，原型未提供 | 人工配置与协调仍多 |

产能、人力成本、质量稳定性和资产留存是上述功能支持的业务目标，实际改善程度需在真实生产中验证。

## 3. 本轮补齐与后续顺序

以下三项及权限交接已补齐本地原型交互，现存检查证据与未验证范围见 [原型验证记录](../原型验证记录.md)：

| 优先级 | 已补齐 | 当前范围 | 对应痛点 |
| --- | --- | --- | --- |
| 1 | 公司模板与标准维护 | 新增/编辑模板、默认提示词与参数、初检规则、发布/停用及版本记录 | 公司能维护统一标准，减少对个人经验的依赖 |
| 2 | 公司级资产检索与复用 | 跨任务查看素材，按 SKU、品类、场景筛选，查看来源和版本，引用已批准素材 | 历史素材找得到、可复用，减少重复制作 |
| 3 | 完整交付要求配置 | 明确详情模块、张数和规格；带货视频可调整分镜并确认 | 表达真实上新所需清单，避免数量够但内容不齐 |

**权限与交接已补齐**：四种角色限制维护、制作、审核、采用和下载；停用成员并选择接手人，保留商品、任务、素材及创建/审核历史。本轮为本机角色演示，正式鉴权与公司云存储待接入。

**可以后做**：质量分析看板、图片区域/视频时间标注、更多行业扩展和 Agent。已有审核原因与版本记录可先用于积累数据；这些是优先顺序建议，不删除 PRD 已定义的阶段要求。

**正式上线必须接通**：真实模型与媒体输入、真实一致性初检、公司存储与权限、后台队列与恢复、调用记录与成本授权、查单防重及真实文件交付。水印与必要标识的处理在选择模型服务时明确，不必先增加专门页面。

当前原型必做缺口已补齐；下一阶段优先接通真实生产与公司数据服务。
