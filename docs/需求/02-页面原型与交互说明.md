# 电商素材生产工作台｜页面原型与交互说明

> v4.7 · 2026-11-20 · 已补齐片段规则与三入口参考筛选 · [概览](../../README.md) · [PRD](01-产品需求文档-PRD.md) · [正式验收标准](01-产品需求文档-PRD.md#7-验收标准)

本文件描述 [当前可交互原型](../../prototype/index.html) 的页面与操作。业务目标和正式接入要求见 PRD；本文件第 7 节集中说明模拟边界。本版补入公司模板管理、跨任务资产、完整交付配置和权限交接；初检仍为本地模拟；双提示词、独立高级编辑页及固定 960px 首页布局不再作为当前设计要求。

## 1. 导航、商品与制作任务

### 1.1 当前导航

| 导航/入口 | 当前操作 | 对应功能 |
| --- | --- | --- |
| 创作工作台 | 顶部切换“生成 / 画布 / 批量制作”，编辑当前任务并浏览结果 | F02～F04、F07～F09、F12、F16～F18 |
| 商品资料 | 搜索与品类筛选、查看实拍和已确认信息、添加商品、用此商品制作 | F01 |
| 案例灵感 | 关键词、图片/视频及品类组合筛选，预览、添加/移除参考 | F05 |
| 审核中心 | 当前任务初检中、已拦截、初检异常、待终审、已驳回、已批准及全部，检查原因、实拍对照与人工决定 | F10、F11 |
| 资产与交付 | 本次交付配置、独立位置采用/补齐/导出，公司跨任务素材检索与引用 | F13 |
| 公司管理 | 模板草稿/发布/版本/启停、成员权限和停用交接、操作记录 | F06、F10、F11、F13 |
| 全部任务 / 当前任务 | 查找、继续或切换已有任务；工作台和任务列表提供“新建制作” | 跨页面任务上下文 |
| 使用指南 | 介绍制作、人工审核、交付与清除演示修改；规则按需展开 | 使用辅助 |

侧栏新增“公司管理”，提供模板与标准、成员与权限、操作记录。模板支持草稿编辑、默认提示词/参数/初检规则、明确发布、启停和历史版本；三个制作入口均可选择适用模板，应用前确认覆盖范围。发布不自动修改已有草稿，历史生成保留当时模板与规则快照，停用后阻止新提交。

桌面侧栏支持完整导航与图标栏切换，记住手动偏好；首次进入窄桌面默认收起。手机通过菜单打开文字抽屉，支持关闭、遮罩与 Escape，手机操作不改变桌面折叠偏好。

### 1.2 新建制作与添加商品

1. 在工作台或全部任务页点击“新建制作”。先搜索/选择一件或多件商品，再选择本次所需主图、详情素材或带货视频；名称按商品、内容和日期自动生成，可在创建时填写或进入后修改。
2. 点击“进入制作”后建立独立任务，带入商品资料并聚焦提示词；创建本身不启动生成。未选择商品或内容时提示补齐。
3. 选择过程中可“添加新商品”：上传实拍，填写名称、SKU、品类和已确认的颜色/规格，核对后“保存并选中”。成功返回原选择并自动选中，新商品保存到本机商品库；返回、关闭或 Escape 均保留父级已选商品、内容和名称。
4. 商品资料页可“保存商品”，也可“保存并开始制作”。支持 JPG、PNG、WebP 实拍，单张不超过 10 MB；图片经压缩保存，重复 SKU、缺资料、未确认或本机空间不足时显示错误，不假报保存成功。
5. 商品卡片“用此商品制作”开启独立制作的选择流程；取消不改变原任务。给当前任务加商品必须从“添加商品到本次制作”明确操作，成功后保留现有草稿和结果。批量项的商品选项只列当前任务成员。

新任务按商品 × 所选内容整理交付，只选主图时不要求补详情和视频。后续明确生成其他用途时扩展本次范围；旧任务没有范围字段时仍沿用三类内容，保留既有采用。原型目前每个 SKU/用途一个交付位置，正式多模块、多张数清单见 PRD。

### 1.3 继续任务与下一步

“全部任务”可按名称、商品或 SKU 搜索，显示制作中、待终审和交付配齐数量；“继续创作”恢复任务。当前任务名下拉只切换最近任务或查看全部，不提供新建按钮。

工作台持续显示当前任务、商品和按状态变化的下一步，例如待终审、选择交付版本、继续补齐、核对并导出。审核与交付保留任务名、切换和“返回此任务创作”，不增加创建入口。

切换任务保存各自模式、节点、商品与草稿；当前会话中的模拟生成继续写回原任务。审核与交付切换任务后仍在原页面并刷新范围，不能把一个任务的生成结果或审核决定写入另一个任务。

## 2. 生成页与提示词（F02、F05～F09、F16～F18）

### 2.1 唯一输入与参数

生成页采用单一完整提示词输入。商品与创作模式共用桌面顶栏，点击当前商品可切换任务内 SKU、看实拍或补充实拍，再从实拍页查看资料。商品事实随 SKU 绑定，参考只影响表达。

输入框左侧添加案例参考，正文直接编辑实际提交提示词；优化/撤销和解析收进底部“创作工具”。图片/视频、模型、比例/清晰度、数量及视频时长从底部参数入口按需展开；用途与公司风格在“创作设置”。切换风格或参数不覆盖手写正文，修改本次配置不改变公司模板。

快捷词、优化及解析只对当前对象提供可编辑表达，不自动生成、批准或确认分镜。参考解析先展示预设建议，由用户决定应用；原型没有真实识图或视频理解能力。旧草稿中的创作描述并入唯一提示词，保留原文；当前不再提供第二个描述框或高级完整词编辑页。

### 2.2 确认、结果与布局

快捷与画布的“创作设置 → 素材用途”均可选择带货成片或单段片段。点击“生成图片 / 生成视频”核对当前商品、用途、数量、规格与输入范围；只有带货成片须确认分镜，片段不强制完整分镜、不计成片交付。原型不显示价格、费用勾选或费用确认。生成和保存为本地模拟，保存成功后自动进入模拟 AI 初检；未通过拦截，通过后待人工终审。

结果位于输入区下方，按可用宽度排列；图片按配置比例完整呈现。结果栏包含媒体分类和命中数量，商品范围、审核状态与排序按需筛选。默认只看当前 SKU，可明确切到全部 SKU；卡片展示名称、状态、采用与版本，详细规格在详情中查看。终审说明从标题旁入口展开，多选时才显示批量操作条。

桌面商品行、输入和结果共享内容边界，工作区最大宽度 1440px，默认提示词编辑区不低于 88px。短屏根据剩余高度缩小预览，优先完整展示首排图片及卡片信息，更多结果在列表内滚动；大幅手动拉高输入框时仍允许工作区滚动。手机图片保持完整比例与自然页面滚动。

## 3. 批量制作（F07～F09、F16～F18）

### 3.1 清单与侧边编辑

“批量图片 / 批量视频”分别维护清单和提交。一次需求建立一个独立生成项，同 SKU 不同画面也可建多项；单次同一提示词生成多张候选不等于多个独立需求。

桌面采用紧凑清单与固定右侧编辑区，选项编辑、公共设置、分镜和结果切换右侧内容，不在行内展开大表单。约 1280×600 内容区、至少五项时，编辑仍应保留五行与底部提交区，长文本和结果单独滚动。小于 1100px 使用覆盖式抽屉，手机采用底部面板；关闭、Escape 和焦点返回保留当前草稿。

清单突出画面需求，商品及 SKU 为辅助信息；右侧以“序号 · 需求摘要”标识当前项。输入与首页采用同一结构：商品/用途摘要、绑定实拍、可选参考和唯一完整提示词，优化/撤销及模型、清晰度、比例、数量、时长均在输入框底部；业务创作起点在框外下方。取消独立高级设置页及双文本输入，参数或参考变更不重新拼接正文。

### 3.2 公共设置与提交规则

| 操作 | 行为 |
| --- | --- |
| 新增 / 复制 | 创建未提交项；复制已提交项只复制配置，不重发原调用或继承批准 |
| 公共设置 | 展示默认规格及适用范围，仅更新仍继承对应字段的未提交项，保留独立覆盖和已提交快照 |
| 恢复默认 | 逐字段恢复后继续继承公共值；提示词恢复可撤销；整项恢复公共设置及删除须确认 |
| 更换商品 / 用途 | 从摘要进入，商品限本任务成员；清理错 SKU 引用，保留手写提示词时重新核对商品事实 |
| 表达辅助 | 创作起点、优化和参考解析只作用当前项，建议可编辑或撤销，不自动启动整批 |
| 提交范围 | 当前媒体全部未提交项；显示项数和总输出数量，如“待提交 3 项 · 共 4 张”，按钮显示输出数量 |
| 校验失败 | 阻止整次提交、标记具体项并定位第一项错误；修正或明确删除，不静默跳过 |
| 重复点击 | 在途/完成项不重新提交；无草稿时禁用按钮，主动再次生成须明确创建新项 |

批量图片每项独立配置用途、提示词、参考、模型、规格和张数；实拍随 SKU 绑定，当前批量面板不另设上传控件。批量视频另有片段/带货成片、时长和条数；引用已就绪参考，同 SKU 成品须已批准，不自动调度另一批尚未完成的输出。

带货成片逐项进入独立分镜确认视图，检查镜头时段、总时长、商品事实并确认；改动该项输入、用途、参考或参数后确认失效，单纯切项或返回不失效。视频支持 1–12 个镜头，编辑画面、文案和正整数秒时长；总时长须等于 6/12/15 秒配置，空画面或时长失配阻止确认。三个入口采用同一校验，切换面板保留确认，输入变化后确认失效。片段不计带货成片交付；原型仍用静态关键帧预览。

### 3.3 执行与恢复

提交冻结各项输入，每份输出独立记录排队、生成、保存、结果与尝试步骤。容量内并行、超出排队，先完成可先查看；一份失败不阻塞其他输出。生成失败只重试失败输出，保存失败只重存，成功结果及标识保留。正常页面没有异常注入或“演示工具”入口。

当前执行由本地模拟驱动，刷新按原记录恢复演示；关闭页面时没有后台服务继续生成。正式接入须支持后台已接受任务持续执行、供应商查单、防重复调用及真实并发验证，本地动画不作为这些能力的证明。

## 4. 画布制作（F03、F04、F05、F07、F12）

**后续设计基准（2026-11-20 用户确认）：**以 [LibTV 六张画布截图及拆解](../参考/LibTV/画布设计基准.md)为基准，按本项目用途精简。采用紧凑节点、选中后的媒体操作栏、画布内生成浮层，以及“连线—参考缩略图—可选正文引用标签”的对应关系；保留现有 SKU、初检、终审、采用与交付规则。空白态聚焦商品素材、图片生成和视频生成，表达辅助收纳到创作设置；多节点时提供关系高亮与定位。以上是后续设计要求，当前 HTML/JS 原型尚未据此重排。

画布占满工作区，支持商品实拍、案例、生成节点和关联结果，提供移动、缩放与整理。默认按当前 SKU 展示，可切全部 SKU。快捷与画布共用同一节点草稿，切换不复制调用或丢输入。

点击节点，在画布内部浮层编辑与首页相同的提示词和参数；参考选择、素材详情、生成确认、视频分镜确认、进度和结果均留在画布边界内，不出现外置编辑栏挤压画布。关闭或 Escape 返回原节点，小屏采用画布内部面板。

来源节点点“引用”，目标节点点“输入”完成引用，可在引用管理中移除。商品实拍固定绑定自身 SKU；成品只引用同 SKU 已批准版本，案例按使用范围限制。不能把跨 SKU 实拍/成品接入当前商品。移动、缩放、选中或连接本身不启动生成，新版本出现不自动替换上游或级联重跑。

生成结果作为对应节点下方的结果节点展示。预览或“查看结果”可在画布内检查、人工审核或创建返工节点。返工绑定具体父版本和意见，不修改其他输出；新结果重新待审。当前没有生产级图片区域/视频时间标注、像素级局部编辑或完整工作流编排。

## 5. 商品、案例、人工审核与交付（F01、F05、F10～F13）

### 5.1 商品与案例

商品资料页突出实拍、名称、SKU、品类、规格与确认信息，支持搜索、筛选、查看资料及“用此商品制作”。新增资料在当前浏览器保存；创作区额外上传的临时补充图仅保留会话，刷新后须重新上传。

三个制作入口均支持按关键词、媒体及品类组合筛选案例，并预览图片或视频分镜：快捷与画布在参考弹窗内操作，批量在单项或公共设置的参考区筛选、选择并预览。筛选及预览不改变提示词、模板、数量或已选参考；已选项即使位于筛选范围外也保留并标注。案例灵感页使用相同筛选规则，图片完整预览，视频当前展示分镜。添加参考显示目标和已添加状态，可移除并返回创作，选择随草稿保存。外部来源使用范围未确认时只可浏览，不能加入生成；案例表达不替换当前 SKU 事实。

### 5.2 AI 初检、自动拦截与人工终审

三个制作入口在保存结果后自动进入 AI 初检。当前以固定样例演示商品一致性、适用人物与场景检查，检查记录标注“模拟结果”，并显示 SKU、素材版本、规则版本、依据和时间；不读取真实图像/视频、不伪造采样覆盖。

初检通过后进入待终审，未通过自动拦截并显示问题；拦截项不能批准、采用、引用或交付，可调整后返工。初检异常保留生成结果，支持仅重试检查，不重新生成；检查中不可人工放行。默认多份输出包含通过与拦截样例，仅用于体验分流，不代表模型准确率。

历史待审重新进入模拟初检；历史人工批准/驳回保留原决定并明确标为未记录初检。旧批量已保存输出复用原文件标识进入初检，不重新生成。

审核中心默认当前任务待终审，初检中/已拦截/初检异常/待审/驳回/批准/全部筛选同时显示数量。列表突出原因与处理操作；打开终审，桌面并排、手机上下对照生成结果与商品实拍，支持放大，底部批准/驳回操作保持可见。规格及版本来源按需展开，可继续下一份待审。

批准只针对当前版本，驳回必填原因，返工保留原文件、原因和父版本。新版本重新初检，通过后人工审核，旧批准不继承。批准不自动采用，必须明确选择交付版本；当前体验身份作为审核人保存；真实登录、并发决定冲突与批准撤回仍待后台接入。

### 5.3 资产与交付

默认打开“本次交付”，按当前任务商品、模块、数量和规格列出独立位置与缺口。“配置交付要求”可编辑模块名称、张数、比例、清晰度与视频时长；核对后确认保存，保留匹配采用并清理失配位置，不删除生成文件。每项 1–6 份，任务上限 100 个位置，同 SKU/用途下模块名不能重复。

每个位置采用一个有效批准且 SKU、模块、比例、清晰度、视频时长均匹配的版本；同一版本只占一个位置，替换须明确确认。视频片段不计带货成片位置。缺口按现有状态进入选择采用、人工审核、查看问题或继续制作，保留其他草稿。生成数、批准数和已配齐位置数分别统计。

导出前核对名称、版本、文件类型和缺口；配齐导出完整包，未配齐但已有采用可导出明确列缺口的部分包。ZIP 为真实下载操作，内容是本地排版 PNG 示例、视频分镜 TXT、交付清单及说明，视频不含真实成片，不能当正式商用交付。文件名含模块、位置、素材 ID 和版本；PNG 按比例及所选最大边输出，清单列实际规格、分镜、来源版本和缺口。导出前后再次校验任务、清单版本、采用和下载权限。

切换“公司素材”，可跨任务按素材名称/SKU 搜索，组合品类、场景、媒体、来源任务及批准状态过滤。来源详情显示任务、创建人、模板和版本；仅批准素材可引用至同 SKU、媒体兼容的节点或未提交批量项，引用保留出处，不继承批准或采用状态。批量引用替换其单份参考；提交时重新验证来源。

本轮界面密度优化：公司管理移除空白桌面头部和宣传横幅，模板首屏只展示名称、适用范围、状态、版本和规格；搜索、品类、媒体、状态筛选与“查看配置”将完整提示词收进详情。资产与交付默认展示紧凑的本次交付摘要，支持“只看待补齐”，位置状态区分未制作、初检中、待终审、已拦截、已驳回、待采用和已采用。切换公司素材后显示公司范围标识，任务/返回上下文不重复出现；场景、来源任务、审核状态收进“更多筛选”，当前筛选可移除并显示“结果数 / 公司总数”。筛选仅改变列表显示，交付统计、采用和导出仍按当前任务完整清单计算。

### 5.4 成员权限与交接

公司管理的“成员与权限”提供管理员、设计师、审核员和只读角色；具体权限见 PRD 4.9，下载还受单独授权限制。侧栏头像可切换有效体验身份；按钮状态及操作处理均校验权限。不能停用当前身份或移除最后管理员。停用时明确接手人，转移负责的任务和商品，保留全部素材、创建人、审核人和版本。操作记录保存在本机；角色切换不替代真实登录和服务端鉴权。

## 6. 正式接入与第二阶段 Agent

正式第一阶段须接入真实图片/视频模型、输入媒体、真实一致性检查、镜头内容验证、后台队列和关页接续、公司商品与资产系统、权限、版本与下载审计。请求及费用状态以后台记录为准，重试不能重复调用或记账；当前不增加价格或费用确认界面，真实授权交互另行确认。

第二阶段才增加 Agent 辅助：读取有权限的商品、任务、配置和已选版本，提出可编辑计划，在明确授权范围内执行并接续人工修改；不代替人工终审。当前没有 Agent 面板、真实规划执行或自然语言后台调度能力。

## 7. 当前原型状态与查看方式

入口为 [index.html](../../prototype/index.html)。可直接双击体验主要界面；上传、持久化及 ZIP 下载推荐使用本地 HTTP，启动命令见 [README](../../README.md#查看原型)。使用同一浏览器和访问地址，便于保留本机演示记录。
