# 造物 Studio 开发指南

当前工程按 `apps/web`、`apps/server` 和 `deploy` 分区。生产功能只在 `develop` 分支开发，模块完成后先验证、再单独提交和推送。

## 本地环境

需要 Node.js 20、pnpm 9、Python 3.10+、uv 和 Docker。复制 `.env.example` 为本地 `.env`，填写 `ARK_API_KEY`。`.env` 不进入 Git。

## 前端命令

```bash
pnpm --dir apps/web install
pnpm --dir apps/web lint
pnpm --dir apps/web typecheck
pnpm --dir apps/web test
pnpm --dir apps/web build
pnpm --dir apps/web check:lines
pnpm --dir apps/web dev
```

`pnpm --dir apps/web generate:api` 会从 FastAPI 应用导出 OpenAPI，再生成前端类型。生成结果提交前必须检查没有未预期的工作树变化。

## 后端命令

```bash
uv sync --project apps/server --dev
uv run --project apps/server ruff check apps/server/app apps/server/tests
uv run --project apps/server mypy apps/server/app
uv run --project apps/server pytest apps/server/tests
uv run --project apps/server alembic -c apps/server/alembic.ini upgrade head
uv run --project apps/server uvicorn app.main:app --app-dir apps/server --reload
```

健康检查地址为 `GET /api/v1/health`，成功响应为 `{"status":"ok","service":"studio-api"}`。

图片供应商适配器烟测：

```bash
PYTHONPATH=apps/server uv run --project apps/server python -m app.entrypoints.smoke_image
```

命令使用 `ARK_API_KEY`、`ARK_BASE_URL`、`ARK_IMAGE_MODEL` 和 `ARK_TIMEOUT_SECONDS`，成功时立即下载 URL 结果到 `.artifacts/ark-image-smoke/`。供应商 429 只输出状态、请求 ID、错误码和等待信息，不会自动重试。

## 基础设施

```bash
docker compose -f deploy/docker-compose.yml up -d
```

本地 Compose 提供 MySQL、Redis 和 MinIO。正式部署还需要 Nginx/HTTPS、私有对象存储凭据和备份策略，不能直接复用开发默认密码。

## 模块提交检查

```bash
git status --short
git diff --check
git diff --cached --check
git diff --cached --stat
git push origin develop
git merge-base --is-ancestor <module-commit> origin/develop
```

提交内容只包含当前模块的代码、迁移、测试和验收记录。模型调用、文件和日志中的密钥必须脱敏。
