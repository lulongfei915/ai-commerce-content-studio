# 造物 Studio 开发指南

当前工程按 `apps/web`、`apps/server` 和 `deploy` 分区。生产功能只在 `develop` 分支开发，模块完成后先验证、再单独提交和推送。

## 本地环境

需要 Node.js 22、pnpm 11、Python 3.10+、uv 和 Docker。复制 `.env.example` 为本地 `.env`，填写 `ARK_API_KEY`。`.env` 不进入 Git。

## 前端命令

```bash
pnpm --dir apps/web install --frozen-lockfile
pnpm --dir apps/web lint
pnpm --dir apps/web typecheck
pnpm --dir apps/web test
pnpm --dir apps/web build
pnpm --dir apps/web check:lines
pnpm --dir apps/web dev
```

`pnpm --dir apps/web generate:api` 会从 FastAPI 应用导出 OpenAPI，再生成前端类型。生成结果提交前必须检查没有未预期的工作树变化。

## 后端命令

```bash
uv sync --project apps/server --dev
uv run --project apps/server ruff check apps/server/app apps/server/tests
uv run --project apps/server mypy --config-file apps/server/pyproject.toml apps/server/app
uv run --project apps/server pytest apps/server/tests
uv run --project apps/server alembic -c apps/server/alembic.ini upgrade head
uv run --project apps/server uvicorn app.main:app --app-dir apps/server --reload
```

健康检查地址为 `GET /api/v1/health`，成功响应为 `{"status":"ok","service":"studio-api"}`。

图片供应商适配器烟测：

```bash
PYTHONPATH=apps/server uv run --project apps/server python -m app.entrypoints.smoke_image
```

命令使用 `ARK_API_KEY`、`ARK_BASE_URL`、`ARK_IMAGE_MODEL` 和 `ARK_TIMEOUT_SECONDS`，成功时立即下载 URL 结果到 `.artifacts/ark-image-smoke/`。供应商 429 只输出状态、请求 ID、错误码和等待信息，不会自动重试。

视频供应商适配器烟测需要可从 `PATH` 调用的 `ffprobe`。

```bash
PYTHONPATH=apps/server uv run --project apps/server python -m app.entrypoints.smoke_video
```

默认使用 `ARK_VIDEO_MODEL=doubao-seedance-2-0-260128` 提交一次付费的文生视频任务。命令输出任务 ID，最多等待 30 分钟，下载并验证 5 秒、720p、16:9 的 MP4，保存到 `.artifacts/ark-video-smoke/`。轮询或下载中断时，给同一命令追加 `--task-id <任务 ID>` 即可继续查询和下载原任务。

## 基础设施

```bash
docker compose -f deploy/docker-compose.yml up -d
```

本地 Compose 在回环地址提供 MySQL、Redis 和 MinIO。MinIO 首次启动会构建开发镜像，下载并校验官方发行二进制。需要更换 MySQL 宿主机端口时，可设置 `STUDIO_MYSQL_PORT`，并同步更新本地 `DATABASE_URL` 的端口。`STUDIO_MYSQL_IMAGE` 和 `STUDIO_REDIS_IMAGE` 可指定同版本的镜像源。

正式部署使用独立的 Nginx/HTTPS、凭据和备份配置。

## 图片生产

迁移至 `0008_asset_family` 后，在仓库根目录为 API、Worker 和调度器提供同一份环境配置。分别在独立进程执行以下命令。

```bash
PYTHONPATH=apps/server uv run --project apps/server celery -A app.entrypoints.worker:celery_app worker --loglevel=INFO
PYTHONPATH=apps/server uv run --project apps/server python -m app.entrypoints.scheduler
```

`IMAGE_BUDGET_CENTS` 是每租户累计费用上限（人民币分），`IMAGE_CEILING_CENTS` 和 `ASSISTANCE_CEILING_CENTS` 分别为每张图片、每次文本或视觉调用预留的成本上界。三项默认均为零。启用真实调用时按已批准的预算、合同费率及最大输入输出配置，`ARK_VISION_MODEL` 填写账号已开通的多模态模型或 Endpoint。可通过 `STORAGE_SIGNED_ENDPOINT` 指定模型可访问的 HTTPS 对象存储地址，签名有效期 5 分钟。仅本地可达的存储使用固定版本图片的 Base64 输入。

数据库中的 `image_steps` 保存原请求 ID、结果位置、费用预留和结算状态。`studio_model_calls` 保存辅助调用及历史初检记录。同步图片请求超时进入 `unknown`。管理员取得原请求的供应商或账单凭据后可通过 `POST /outputs/{id}/reconcile` 一次性核实费用与受理事实。保存失败使用同一结果地址，归档成功后直接待人工审核。升级 `0009_manual_review` 前应停止旧调度器与 Worker，以免旧进程继续派发初检。

## 模块提交检查

```bash
git status --short
git diff --check
git diff --cached --check
git diff --cached --stat
git push origin develop
git merge-base --is-ancestor <module-commit> origin/develop
```

提交内容只包含当前模块的代码、迁移、测试和验收记录。模型调用、文件和日志中的密钥必须脱敏。

## 登录与私有媒体

先在 MinIO 创建私有桶 `studio-private`。在本地 `.env` 配置 `DATABASE_URL`、`REDIS_URL`、`STORAGE_ENDPOINT`、`STORAGE_ACCESS_KEY` 和 `STORAGE_SECRET_KEY`。开发容器用的 MinIO 凭据见 Compose 配置。视频接收需要 `ffprobe` 和 `ffmpeg`。后端容器镜像已安装这两项工具。

```bash
uv run --project apps/server alembic -c apps/server/alembic.ini upgrade head
PYTHONPATH=apps/server uv run --project apps/server python -m app.entrypoints.bootstrap_tenant \
  --slug your-company --name '你的公司' --email admin@example.com
```

初始化命令交互式读取管理员密码。需要动态验证码时先配置 `AUTH_TOTP_KEY`，然后在初始化命令加 `--totp`，按提示输入验证器的 Base32 密钥和当前验证码。使用上面的后端和前端启动命令后，从 Vite 页面登录。非开发环境使用 HTTPS，`AUTH_PUBLIC_ORIGIN` 设置为工作台的完整来源，例如 `https://studio.example.com`。MySQL 和 Redis 由应用配置读取。

私有文件调用顺序为 `POST /api/v1/files/uploads`、`PUT` 返回的 `upload_path` 并以原始文件作为请求体、`POST /api/v1/files/{id}/complete`。三步都需要登录会话和 `X-CSRF-Token`。文件元数据可用 `GET /api/v1/files/{id}` 读取。下载使用 `/content`，支持单段 HTTP `Range`。重新连接须持有有效会话和下载授权。确立新的下载授权或修改成员身份由对应成员模块处理。
