# M1-04 实施与验证

按 PRD §4.1～4.3、详细设计 §3～4、原型的公司模板和快捷创作，以及已验证的 Seedream 5.5 能力推进。

1. `apps/server/app/modules/cases/` 实现案例目录、私有媒体预览和用途授权。用 `apps/server/tests/module04/test_creation.py` 核对未授权案例可浏览、不可用于生产，以及错租户和未就绪文件的处理。
2. `apps/server/app/modules/templates/` 分开保存可编辑草稿与不可变发布版。管理员可发布、停用、恢复。测试 V1/V2 的历史内容及版本冲突。
3. `apps/server/app/modules/creation/` 保存任务成员 SKU、用途、一个提示词、模型规格、选定模板版与稳定引用。应用模板替换模板引用，保留独立引用，已有提示词按显式选项保留或替换。用服务端前置校验定位资料和引用问题，交给 M1-06 提交链路复用。
4. `apps/web/src/features/{templates,cases,creation}/` 接入公司管理与任务快捷编辑，组件依赖对象接口，画布和批量可复用。浏览器验证案例检索、显式应用以及刷新恢复。
5. 用 Alembic 验证 MySQL，重新生成 OpenAPI，运行 Ruff、mypy、pytest、前端 lint、构建和行数检查。记录 AC-06～08、35、36 的本模块结果，提交 `[M1-04] 实现公司模板、案例与共用创作草稿` 并推送 `develop`。
